What is Lynux Webs?

Lynux Webs is a specialized, simulated Linux console based on MicroPython, currently designed for graphical calculators and PCs. It provides a unique interactive CLI environment tailored for the Dreamworks enthusiast.

Core Features

Bee Package Manager

The bee installer manages local packages. Use bee catalog to explore available software modules.

Questa Virtual Storage

An integrated storage system designed to manage files, character data, and logs across restricted hardware environments.

PyFetch

A MicroPython-optimized system information tool inspired by Neofetch, displaying your system specs in style.

Calculator Compatibility

Optimized for Casio FX-CG50 and similar graphical calculators with Python support.

The Cinematic Inspiration

Lynux Webs celebrates the spirit of Dreamworks Animation. Key themes include:

  • The Bad Guys (Project Identity & Ms. Tarantula)
  • Kung Fu Panda
  • Ruby Gillman, Teenage Kraken

Future Roadmap

Phase 1: The Interactive CLI Current

Enhancing PyLinux features, adding the pyai chatbot, and refining the "Bee" ecosystem on MicroPython.

Phase 2: Arch Linux Evolution Coming Soon

Transitioning from a simulated script to a full-fledged Linux Distribution based on Arch Linux.

Phase 3: Dreamworks Workspace

Introduction of a graphical desktop environment inspired by Dreamworks aesthetics, similar to WhirlyOS (Pixar).
