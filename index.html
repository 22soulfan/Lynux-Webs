How to use Lynux Webs

1. Installation

Clone the fork to your local machine or calculator environment:

git clone "https://github.com/22soulfan/Lynux-Webs.git"

2. Execution

Run PYLINUX.py via a Python interpreter. On Casio calculators, use the Python add-in.

3. The CLI

Log in as your favorite character or as guest. Use bee catalog to check for packages.
