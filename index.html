About the Project

Lynux Webs is a fork of PyLinux, evolving from a MicroPython simulation on Casio calculators to a fully realized interactive workspace. Built for simplicity and cinematic inspiration.

$ pylinux --info
> Status: Active Development (Alpha)
> Inspired by: The Bad Guys, Ruby Gillman, Kung Fu Panda
> Core: MicroPython / PyLinux Fork

Sister Projects

WhirlyOS

The Pixar-inspired sibling based on Debian/Ubuntu. Focuses on ADHD-aware interfaces and educational tools like Scratch and TuxPaint.

Octopus11

A customized Windows 11 environment inspired by Ruby Gillman, Teenage Kraken. Sleek, blue, and optimized.

OpenMyriad

A modernization of ReactOS compatible with modern Windows 11 apps. Coming 2035.

Roadmap

2025: Foundation

Building the interactive CLI features and the "Bee" package manager. Perfecting the MicroPython experience for portable devices.

2026: Expansion

Introduction of the pyai chatbot and expansion of the character metadata system (using .mchar formats).

2027+: The Great Migration

Transitioning Lynux Webs into a standalone Arch Linux distribution with an ARM-compatible core.

Goals of the Arch Linux Future

Rolling Release

Utilizing Arch Linux's core to provide a constantly updated Dreamworks desktop environment.

Dreamworks Workspace

A dedicated desktop shell designed to feel like the headquarters of the Bad Guys or the ZPD.

Educational Hub

Pre-installed open-source tools for coding and art, without the bloat of intrusive AI.

ARM Support

Native support for Raspberry Pi and other embedded hardware to keep the OS portable.
