Lynux Webs (PyLinux) Commands

Essential commands for the simulated MicroPython environment.

CommandDescription
aboutDisplays details about Lynux Webs.
bee [cmd]Package manager (catalog, install, purge).
cd [dir]Change directory (use / at end).
ls [dir]List files in a directory.
logoffLogs out user and wipes sandbox session.
nano [file]Basic text editor shell.
pwdPrint working directory.
pyfetchSystem information fetcher.
questaAccess virtualized storage system.
pyaiLaunch the experimental chatbot.

Example Usage

MsTarantula@pylinux$ nano notes.txt
# Type content, press enter to save
MsTarantula@pylinux$ ls /

The Bee Package System

Lynux Webs uses the Bee installer for local package management.

Questa Preinstalled

Handles virtual storage logic for characters and files.

PyAI Experimental

Basic chatbot engine for interactive terminal sessions.

Panda-Tools Optional

Utilities for managing .mchar and .pdoc files.

$ bee catalog
Available: questa, pyai, panda-tools
$ bee install pyai

Frequently Asked Questions

Does it work on Casio FX-CG100? Yes, if it has the Python add-in pre-installed.
Can I install XFCE or GNOME on the MicroPython version? No. Graphical Desktop Environments require the real Arch Linux base planned for the future.
What happens if I logoff? All sandbox session data is erased for security and storage efficiency.
Is it open source? Yes, licensed under MIT and forked from hirohamada2014/PyLinux.
